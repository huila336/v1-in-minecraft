V1Mod — браузерная сборка (Minecraft Java 1.20.1 / Forge 47.2.0)

ВАЖНО:
Это только первый прототип: добавляет тестовую сущность с временной моделью зомби.
Это НЕ полноценный управляемый V1 и пока не содержит способностей ULTRAKILL.

Сборка без установки IDE:
1. Создайте репозиторий на GitHub в браузере.
2. Загрузите все файлы и папку из этого архива в репозиторий (включая скрытую папку .github).
3. Откройте вкладку Actions и запустите workflow "Build Minecraft mod" (или дождитесь завершения автоматической сборки).
4. Откройте успешный запуск workflow и скачайте artifact "v1mod-jar".
5. Распакуйте скачанный artifact ZIP. Внутри должен быть файл v1mod-1.0.0.jar.
6. Поместите JAR в папку .minecraft/mods и запустите профиль Forge 1.20.1.

В игре:
 /summon v1mod:v1 ~ ~ ~

Если сборка не проходит:
Откройте Actions → неудачный запуск → Build mod jar и скопируйте сюда последние 30–50 строк ошибки.

ПРИМЕЧАНИЕ:
Для сборки нужны аккаунт GitHub и доступ к GitHub Actions. Для обычных публичных репозиториев GitHub Actions обычно доступен бесплатно в пределах лимитов GitHub.
